# make-knowledge-cards

把一篇文章（粘贴的文本，或本地 Markdown / TXT 文件）转成 **5~8 张知识卡片**，每张卡片包含**标题、核心知识、简明解释、例子或自测问题**，只提取原文中真正重要的知识点。

## 项目解决什么问题

读长文、做笔记时最常见的困扰是：信息过载抓不住重点、读完就忘、笔记零散不成体系。本项目把"文章"自动转化为"可复习的知识卡片"，解决三个问题：

- **抓不住重点**：只提炼原文中真正重要的知识点，跳过观点、逸事和客套话；
- **重复与零散**：自动合并重复内容，一张卡片只讲一个知识点，便于复习；
- **笔记失真**：所有内容忠实于原文，不编造原文没有的信息，信息不足时不强行凑数。

## 主要功能

- **输入灵活**：直接粘贴文章文本，或提供本地 `.md` / `.txt` 文件路径；
- **卡片结构统一**：每张卡片包含标题、核心知识、简明解释、例子或自测问题四个字段；
- **一卡一点**：一个知识点一张卡片，以"读者能否独立理解"为准拆分或合并；
- **自动去重**：跨段落重复出现的知识点合并处理；
- **忠实原文**：不添加原文没有的事实、数据或结论；原文矛盾处如实标注；
- **数量自适应**：5~8 张为目标，信息不足的短文自动产出更少卡片，绝不注水；
- **文体适配**：支持科普文、实用方法文、小说叙事文等（叙事文本提炼人物、关系、环境、情节）；
- **暂不支持**：网页抓取、PDF、Anki 导入、图形界面。

## 安装方法

本技能是**纯指令型 Skill**（仅含 SKILL.md 与 agents/openai.yaml，无脚本、无依赖），安装无需安装任何 Python 包或配置环境：

1. 将 `skills/make-knowledge-cards/` 整个目录复制到 AI 助手的技能目录，例如 `workspace/.user_skills/make-knowledge-cards/`；
2. 或将该目录放入支持技能扫描的项目/环境路径中，助手在技能发现阶段会自动加载；
3. 验证安装：运行官方校验脚本 `scripts/quick_validate.py skills/make-knowledge-cards`，输出 `Skill is valid!` 即安装成功；也可直接让助手把一段文章转成卡片试用。

## 使用方法

1. 把文章直接粘贴给助手，或提供本地 `.md` / `.txt` 文件路径，例如"把 `<本地路径>\article.md` 转成知识卡片"；
2. 助手按技能工作流输出 Markdown 卡片列表，开头为一行总览（来源 + 卡片数）。

触发示例：`帮我做知识卡片`、`把这篇文章卡片化`、`整理这篇笔记的知识点`。

## 输入输出示例

**输入示例**（粘贴文本或文件内容）：

> 德国心理学家艾宾浩斯在 1885 年通过无意义音节实验发现，遗忘在记忆建立后立即开始，并且先快后慢。实验显示：记忆后 20 分钟仍记得约 58% 的内容；1 小时后剩约 44%；1 天后只剩约 33%；6 天后剩约 25%。复习的黄金窗口在遗忘最陡峭的初期，越早复习，越省力。

**输出示例**：

> 来源：<文章标题> ｜ 卡片数：1

### 卡片 1：遗忘曲线：先快后慢

- **核心知识**：遗忘在记忆建立后立即开始且先快后慢，复习的黄金窗口在遗忘最陡峭的初期。
- **简明解释**：艾宾浩斯实验数据显示，记忆后 20 分钟仍记得约 58%，1 小时后约 44%，1 天后约 33%，6 天后约 25%，曲线先急剧下降、之后趋于平缓。
- **自测问题**：按艾宾浩斯数据，记忆建立 1 天后大约还记得多少内容？

## 测试与验证

- 长科普文 → 6 张卡片，重复内容已合并
- 短文（信息不足）→ 2 张卡片，未强行凑到 5 张
- 实用方法文 → 5 张卡片
- 小说叙事文（自撰样例《守灯人的最后一夜》）→ 5 张卡片
- 英文原版（《呼啸山庄》Ch I-II，公共领域文本）→ 8 张卡片
- 通过官方 `quick_validate.py` 校验：`Skill is valid!`
